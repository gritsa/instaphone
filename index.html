Instaphone

A browser softphone for Twilio Voice

Personal use only. This app mints Twilio access tokens entirely in your browser using your API credentials. That model is not secure for distribution — anyone with access to this browser profile could extract your keys. Use it only on your own machine, with a restricted API key, and never ship it to others.
